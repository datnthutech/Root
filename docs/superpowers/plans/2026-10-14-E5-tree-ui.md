**Goal:** Màn hình `/tree` dùng dữ liệu thật: chế độ 1 (toàn cảnh dòng họ), 2 (tập trung một người), 3 (lọc nội/ngoại); tìm kiếm nhảy tới người; bản đồ thu nhỏ; thu gọn/mở nhánh; thẻ hover sau 300 ms; popup 3 tab (Hồ sơ, Gia đình, Sơ yếu lý lịch); mở sẵn vị trí của chính mình khi đăng nhập; ảnh thật ở mức phóng gần.

**Architecture:** Dùng lại `computeLayout` (worker), `TreeRenderer`, `QuadTree`, `lodForScale` của E1 — mở rộng, không viết lại thuật toán. Dữ liệu: `loadClanGraph` (If-None-Match + IndexedDB) / `loadFocusGraph` → `useTreeData` (graph + collapsed → worker layout, cache theo ETag) → `TreeCanvas` (React bọc renderer). **Tech Stack:** React 18, TanStack Query, Ant Design, PixiJS 7, Vitest + Testing Library, fake-indexeddb.

**Spec:** `docs/superpowers/specs/2026-10-14-gia-pha-design.md`; tài liệu gốc mục "Chế độ xem và tương tác", "Hiệu năng và độ mượt".

## Global Constraints

- Mọi lệnh FE chạy ở `src/Root/frontend`; lệnh BE ở `src/Root/backend`.
- Hover: thẻ nhỏ hiện sau **300 ms**, không có tab; click (chạm trên điện thoại): mở popup có tab, giữ đến khi đóng. Thiết bị không có hover (`(hover: none)`) không bao giờ hiện thẻ hover.
- Mức chi tiết theo độ phóng (E1): `< 0.3` chấm; `< 0.8` ô chữ; còn lại ô đủ ảnh.
- Thu gọn mặc định các nhánh sâu hơn **4 đời** (hằng `DEFAULT_COLLAPSE_DEPTH = 4`).
- Chế độ 3 (nội/ngoại) chỉ áp cho chế độ 1; chế độ 2 bỏ qua `side`.
- URL là nguồn sự thật của chế độ: `/tree?mode=clan&clan=1&side=both` hoặc `/tree?mode=focus&person=12&up=3&down=3`.
- Sơ yếu lý lịch lưu dạng **Markdown tối giản**: `**đậm**`, `*nghiêng*`, dòng bắt đầu `- ` là danh sách, xuống dòng giữ nguyên; **không** render HTML.
- Ngày hiển thị `dd/MM/yyyy` (DAY), `MM/yyyy` (MONTH), `yyyy` (YEAR), `Không rõ` (UNKNOWN/thiếu). Người còn sống với VIEWER chỉ có `birthYear` (BE không gửi `birthDate`).
- Giao diện chạy được ở 375 px (popup gần toàn màn hình).

```java
package vn.giapha.dev;

import java.sql.Date;
import java.util.*;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.support.GeneratedKeyHolder;
import org.springframework.stereotype.Component;
import vn.giapha.clan.ClanMemberService;

/** Chỉ dùng cho dev/đo hiệu năng: bật bằng DEV_SEED_PERSONS=N. */
@Component
public class DevSeedRunner implements ApplicationRunner {
    private final JdbcTemplate jdbc;
    private final ClanMemberService members;
    private final int total;

    public DevSeedRunner(JdbcTemplate jdbc, ClanMemberService members, @Value("${app.dev-seed.persons}") int total) {
        this.jdbc = jdbc;
        this.members = members;
        this.total = total;
    }

    private long person(String name, String gender, int year, boolean alive) {
        GeneratedKeyHolder kh = new GeneratedKeyHolder();
        jdbc.update(con -> {
            var ps = con.prepareStatement("""
                INSERT INTO person(full_name, gender, birth_date, birth_precision, is_alive, death_date, death_precision)
                VALUES (?,?,?,'YEAR',?,?,?)""", new String[]{"id"});
            ps.setString(1, name);
            ps.setString(2, gender);
            ps.setDate(3, Date.valueOf(year + "-01-01"));
            ps.setBoolean(4, alive);
            ps.setDate(5, alive ? null : Date.valueOf((year + 70) + "-01-01"));
            ps.setString(6, alive ? "UNKNOWN" : "YEAR");
            return ps;
        }, kh);
        return kh.getKey().longValue();
    }

    private long union(long a, long b) {
        return jdbc.queryForObject("INSERT INTO union_rel(partner_a_id, partner_b_id, union_order) VALUES (?,?,1) RETURNING id",
            Long.class, a, b);
    }

    @Override
    public void run(ApplicationArguments args) {
        if (total <= 0) return;
        Integer clans = jdbc.queryForObject("SELECT count(*) FROM clan", Integer.class);
        if (clans != null && clans > 0) return;

        Random rnd = new Random(42);
        int[] count = {0};
        record Lead(long id, String gender, int year) {}
        Deque<Lead> queue = new ArrayDeque<>();
        long root = person("Tổ Mẫu", "M", 1800, false);
        count[0]++;
        queue.add(new Lead(root, "M", 1800));
        List<long[]> links = new ArrayList<>();   // {parent, child, union}
        while (!queue.isEmpty() && count[0] < total) {
            Lead p = queue.poll();
            long sp = person("Vợ/chồng " + p.id(), p.gender().equals("M") ? "F" : "M", p.year() + rnd.nextInt(6), p.year() > 1950);
            count[0]++;
            long u = union(p.id(), sp);
            int kids = 1 + rnd.nextInt(4);
            for (int i = 0; i < kids && count[0] < total; i++) {
                int y = p.year() + 22 + i * 2;
                String g = rnd.nextBoolean() ? "M" : "F";
                long c = person("Người " + (count[0] + 1), g, y, y > 1950);
                count[0]++;
                links.add(new long[]{p.id(), c, u});
                links.add(new long[]{sp, c, u});
                queue.add(new Lead(c, g, y));
            }
        }
        jdbc.batchUpdate("INSERT INTO parent_child(parent_id, child_id, union_id) VALUES (?,?,?)", links, 1000, (ps, l) -> {
            ps.setLong(1, l[0]);
            ps.setLong(2, l[1]);
            ps.setLong(3, l[2]);
        });
        long clanId = jdbc.queryForObject("INSERT INTO clan(name, founder_person_id) VALUES ('Họ Mẫu', ?) RETURNING id", Long.class, root);
        members.rebuild(clanId);
    }
}
```

```ts
import type { GraphData } from './types'

export const DEFAULT_COLLAPSE_DEPTH = 4

/** Thu gọn người ở đời thứ `depth` (tính từ gốc = 1) nếu họ có con. */
export function defaultCollapsed(g: GraphData, depth: number): Set<number> {
  const kids = new Map<number, number[]>()
  for (const l of g.links) {
    const list = kids.get(l.parentId)
    if (list) list.push(l.childId)
    else kids.set(l.parentId, [l.childId])
  }
  const level = new Map<number, number>([[g.rootPersonId, 1]])
  const queue = [g.rootPersonId]
  for (let i = 0; i < queue.length; i++) {
    const p = queue[i]
    for (const c of kids.get(p) ?? []) {
      if (!level.has(c)) { level.set(c, level.get(p)! + 1); queue.push(c) }
    }
  }
  const out = new Set<number>()
  for (const [id, lv] of level) if (lv === depth && kids.has(id)) out.add(id)
  return out
}
```

```ts
export async function rawFetch(path: string, init: RequestInit = {}, retried = false): Promise<Response> {
  const headers = new Headers(init.headers)
  if (init.body && !(init.body instanceof FormData) && !headers.has('Content-Type')) {
    headers.set('Content-Type', 'application/json')
  }
  if (accessToken) headers.set('Authorization', `Bearer ${accessToken}`)
  const res = await fetch(`/api/v1${path}`, { ...init, headers, credentials: 'include' })
  if (res.status === 401 && !retried && unauthorizedHandler && !path.startsWith('/auth/')) {
    if (await unauthorizedHandler()) return rawFetch(path, init, true)
  }
  return res
}

export async function toFailure(res: Response): Promise<ApiFailure> {
  let body: ApiErrorBody = { code: 'UNKNOWN', message: res.statusText, details: null }
  try { body = await res.json() } catch { /* giữ mặc định */ }
  return { ...body, status: res.status }
}

export async function http<T>(path: string, init: RequestInit = {}): Promise<T> {
  const res = await rawFetch(path, init)
  if (!res.ok) throw await toFailure(res)
  if (res.status === 204) return undefined as T
  return (await res.json()) as T
}
```

```ts
import { get, set } from 'idb-keyval'
import { http, rawFetch, toFailure } from './http'
import type { GraphData } from '../lib/types'

export type Side = 'both' | 'paternal' | 'maternal'
export interface LoadedGraph { graph: GraphData; etag: string }
export interface ClanSummary { id: number; name: string; founderPersonId: number | null; memberCount: number }
export interface SearchHit { id: number; name: string; gender: 'M' | 'F' | 'U'; birthYear: number | null; deathYear: number | null; alive: boolean; generation: number | null }

async function safeGet<T>(key: string): Promise<T | undefined> { try { return await get<T>(key) } catch { return undefined } }
async function safeSet(key: string, v: unknown) { try { await set(key, v) } catch { /* cache không bắt buộc */ } }

async function fetchGraph(path: string, cacheKey: string | null): Promise<LoadedGraph> {
  const cached = cacheKey ? await safeGet<LoadedGraph>(cacheKey) : undefined
  const headers = new Headers()
  if (cached?.etag) headers.set('If-None-Match', cached.etag)
  let res = await rawFetch(path, { headers, cache: 'no-store' })
  if (res.status === 304) {
    if (cached) return cached
    res = await rawFetch(path, { cache: 'no-store' })   // mất bản lưu: tải lại không điều kiện
  }
  if (!res.ok) throw await toFailure(res)
  const graph = (await res.json()) as GraphData
  const etag = res.headers.get('ETag') ?? ''
  if (cacheKey && etag) await safeSet(cacheKey, { graph, etag })
  return { graph, etag }
}

export const loadClanGraph = (clanId: number, side: Side) =>
  fetchGraph(`/clans/${clanId}/graph?side=${side}`, `graph:${clanId}:${side}`)
```

```ts
export class PhotoStore {
  private cache = new Map<string, string>()
  private pending = new Set<string>()
  private failed = new Set<string>()
  private queue: string[] = []
  private running = 0
  private readonly concurrency: number
  private readonly max: number

  constructor(
    private fetchBlob: (url: string) => Promise<Blob | null>,
    private onLoaded: (url: string) => void,
    opts: { concurrency?: number; max?: number } = {},
  ) {
    this.concurrency = opts.concurrency ?? 6
    this.max = opts.max ?? 400
  }

  get(url: string): string | null {
    const hit = this.cache.get(url)
    if (hit) { this.cache.delete(url); this.cache.set(url, hit); return hit }
    if (!this.pending.has(url) && !this.failed.has(url)) {
      this.pending.add(url)
      this.queue.push(url)
      this.pump()
    }
    return null
  }

  destroy(): void {
    for (const v of this.cache.values()) URL.revokeObjectURL(v)
    this.cache.clear()
    this.queue = []
  }

  private pump(): void {
    while (this.running < this.concurrency && this.queue.length) {
      const url = this.queue.shift()!
      this.running++
      this.fetchBlob(url)
        .then((blob) => {
          if (blob) { this.cache.set(url, URL.createObjectURL(blob)); this.evict(); this.onLoaded(url) }
          else this.failed.add(url)
        })
        .catch(() => { this.failed.add(url) })
        .finally(() => { this.running--; this.pending.delete(url); this.pump() })
    }
  }

  private evict(): void {
    while (this.cache.size > this.max) {
      const [k, v] = this.cache.entries().next().value as [string, string]
      this.cache.delete(k)
      URL.revokeObjectURL(v)
    }
  }
}
```

```tsx
import { Fragment, type ReactNode } from 'react'

function inline(text: string, keyBase: string): ReactNode[] {
  return text.split(/(\*\*[^*]+\*\*|\*[^*]+\*)/g).filter(Boolean).map((part, i) => {
    const key = `${keyBase}-${i}`
    if (part.startsWith('**') && part.endsWith('**') && part.length > 4) return <strong key={key}>{part.slice(2, -2)}</strong>
    if (part.startsWith('*') && part.endsWith('*') && part.length > 2) return <em key={key}>{part.slice(1, -1)}</em>
    return <Fragment key={key}>{part}</Fragment>
  })
}

export function renderBio(text: string): ReactNode {
  if (!text.trim()) return null
  const blocks: ReactNode[] = []
  let para: string[] = []
  let list: string[] = []
  const flushPara = () => {
    if (!para.length) return
    const k = `p${blocks.length}`
    blocks.push(
      <p key={k}>{para.map((line, i) => <Fragment key={i}>{i > 0 && <br />}{inline(line, `${k}-${i}`)}</Fragment>)}</p>,
    )
    para = []
  }
  const flushList = () => {
    if (!list.length) return
    const k = `l${blocks.length}`
    blocks.push(<ul key={k}>{list.map((item, i) => <li key={i}>{inline(item, `${k}-${i}`)}</li>)}</ul>)
    list = []
  }
  for (const line of text.split('\n')) {
    if (line.startsWith('- ')) { flushPara(); list.push(line.slice(2)) }
    else if (!line.trim()) { flushPara(); flushList() }
    else { flushList(); para.push(line) }
  }
  flushPara(); flushList()
  return <>{blocks}</>
}
```

```ts
    const n = this.nodes.get(id), p = this.persons.get(id)
    if (!n || !p) return
    v.render(n, p, this.lod, id === this.selectedId, this.lod === 'full' ? this.texture(p.thumb ? `${p.thumb}` : null) : null)
  }

  private refresh(): void {
    const scale = this.viewport.scale.x
    const lod = lodForScale(scale)
    if (lod !== this.lod) { this.lod = lod; this.releaseAll() }
    this.dots.visible = lod === 'dot'
    this.views.visible = lod !== 'dot'
    const b = this.viewport.getVisibleBounds()
    this.handlers.onViewChange?.({ x: b.x, y: b.y, w: b.width, h: b.height, scale })
    if (lod === 'dot' || !this.index) return

    const visible = this.index.queryRect(b.x, b.y, b.width, b.height)
    const keep = new Set<number>()
    for (const it of visible) {
      keep.add(it.id)
      if (!this.active.has(it.id)) {
        const v = this.pool.pop() ?? new NodeView()
        this.renderView(v, it.id)
        this.views.addChild(v.container)
        this.active.set(it.id, v)
      }
    }
    for (const [id, v] of this.active) {
      if (!keep.has(id)) { this.views.removeChild(v.container); this.pool.push(v); this.active.delete(id) }
    }
  }

  private releaseAll(): void {
    for (const v of this.active.values()) { this.views.removeChild(v.container); this.pool.push(v) }
    this.active.clear()
  }
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react'

export function useHoverCard(delayMs = 300, enabled = true) {
  const [card, setCard] = useState<{ id: number; x: number; y: number } | null>(null)
  const timer = useRef<ReturnType<typeof setTimeout>>()

  const clear = () => { if (timer.current) clearTimeout(timer.current) }
  const onHover = useCallback((id: number | null, pos: { x: number; y: number }) => {
    clear()
    setCard(null)
    if (id === null || !enabled) return
    timer.current = setTimeout(() => setCard({ id, x: pos.x, y: pos.y }), delayMs)
  }, [delayMs, enabled])
  const hide = useCallback(() => { clear(); setCard(null) }, [])
  useEffect(() => clear, [])
  return { card, onHover, hide }
}
```

```ts
        result = await runLayout(base.graph, ids)
        if (base.etag) void setCachedLayout(key, result)
      }
      if (cancelled) return

      lastGraph.current = base.graph
      setLayout(result)
      setLoading(false)
    })()
```

```ts
import type { Side } from '../../api/tree'
import type { TreeParams } from './useTreeData'

const clamp = (n: number) => Math.max(0, Math.min(10, n))
const num = (s: string | null): number | null => { if (s === null || s === '') return null; const n = Number(s); return Number.isInteger(n) ? n : null }

export function parseParams(sp: URLSearchParams): TreeParams | null {
  const clan = num(sp.get('clan')), person = num(sp.get('person'))
  if (sp.has('clan') && clan === null) return null
  if (sp.has('person') && person === null) return null
  const mode = sp.get('mode') === 'focus' ? 'focus' : sp.get('mode') === 'clan' ? 'clan' : person !== null && clan === null ? 'focus' : 'clan'
  if (mode === 'clan' && clan === null) return null
  if (mode === 'focus' && person === null) return null
  const sideRaw = sp.get('side')
  const side: Side = sideRaw === 'paternal' || sideRaw === 'maternal' ? sideRaw : 'both'
  const upN = num(sp.get('up')), downN = num(sp.get('down'))
  return {
    mode, clanId: mode === 'clan' ? clan : null, side, personId: mode === 'focus' ? person : null,
    up: upN === null ? 3 : clamp(upN), down: downN === null ? 3 : clamp(downN),
  }
}

  return p.mode === 'clan'
    ? { mode: 'clan', clan: String(p.clanId), side: p.side }
    : { mode: 'focus', person: String(p.personId), up: String(p.up), down: String(p.down) }
}
```

```tsx
import { useEffect, useRef } from 'react'
import type { LayoutResult } from '../../lib/layout'
import type { ViewInfo } from './TreeRenderer'

export function minimapTransform(layout: { width: number; height: number }, box: { w: number; h: number }) {
  const lw = Math.max(layout.width, 1), lh = Math.max(layout.height, 1)
  const scale = Math.min(box.w / lw, box.h / lh)
  return { scale, ox: (box.w - lw * scale) / 2, oy: (box.h - lh * scale) / 2 }
}

export function Minimap({ layout, view, onNavigate, width = 180, height = 120 }: {
  layout: LayoutResult | null; view: ViewInfo | null; onNavigate(x: number, y: number): void; width?: number; height?: number
}) {
  const ref = useRef<HTMLCanvasElement>(null)
  const dragging = useRef(false)

  useEffect(() => {
    const c = ref.current
    if (!c) return
    const ctx = c.getContext('2d')
    if (!ctx) return
    ctx.clearRect(0, 0, width, height)
    if (!layout) return
    const t = minimapTransform(layout, { w: width, h: height })
    ctx.fillStyle = '#7a8794'
    for (const n of layout.nodes) ctx.fillRect(t.ox + n.x * t.scale, t.oy + n.y * t.scale, Math.max(1.5, n.w * t.scale), Math.max(1.5, n.h * t.scale))
    if (view) {
      ctx.strokeStyle = '#e53935'
      ctx.lineWidth = 1.5
      ctx.strokeRect(t.ox + view.x * t.scale, t.oy + view.y * t.scale, view.w * t.scale, view.h * t.scale)
    }
  }, [layout, view, width, height])

  const navigate = (e: React.PointerEvent<HTMLCanvasElement>) => {
    if (!layout) return
    const rect = e.currentTarget.getBoundingClientRect()
    const t = minimapTransform(layout, { w: width, h: height })
    onNavigate((e.clientX - rect.left - t.ox) / t.scale, (e.clientY - rect.top - t.oy) / t.scale)
  }

  return (
    <canvas ref={ref} width={width} height={height} aria-label="Bản đồ thu nhỏ"
      style={{ background: '#fffd', border: '1px solid #ccc', borderRadius: 6, touchAction: 'none', width, height }}
      onPointerDown={(e) => { dragging.current = true; e.currentTarget.setPointerCapture(e.pointerId); navigate(e) }}
      onPointerMove={(e) => { if (dragging.current) navigate(e) }}
      onPointerUp={() => { dragging.current = false }} />
  )
}
```

```tsx
  const params = useMemo(() => parseParams(sp), [sp])
  const clans = useQuery({ queryKey: ['clans'], queryFn: listClans })
  const canvas = useRef<TreeCanvasHandle>(null)
  const [selected, setSelected] = useState<number | null>(null)
  const [dialogId, setDialogId] = useState<number | null>(null)
  const [view, setView] = useState<ViewInfo | null>(null)
  const hover = useHoverCard(300, canHover())
  const pendingFocus = useRef<number | null>(null)

  const myPerson = user?.linkedPersonId ?? null

  // quyết định màn hình mở đầu khi URL chưa đủ thông tin
  useEffect(() => {
    if (params) return
    if (myPerson !== null) setSp(toSearch({ mode: 'focus', clanId: null, side: 'both', personId: myPerson, up: 3, down: 3 }), { replace: true })
    else if (clans.data?.length) setSp(toSearch({ mode: 'clan', clanId: clans.data[0].id, side: 'both', personId: null, up: 3, down: 3 }), { replace: true })
  }, [params, myPerson, clans.data, setSp])

  const data = useTreeData(params ?? { mode: 'clan', clanId: null, side: 'both', personId: null, up: 3, down: 3 })

  // sau khi bố cục mới của chế độ focus sẵn sàng, đưa camera tới người trung tâm / người được yêu cầu
  useEffect(() => {
    if (!data.layout) return
    const target = pendingFocus.current ?? (params?.mode === 'focus' ? params.personId : null)
    if (target !== null && data.graph?.persons.some((p) => p.id === target)) {
      setSelected(target)
      setTimeout(() => canvas.current?.focusOn(target, 1), 0)
    }
    pendingFocus.current = null
  // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [data.layout])

  const update = (next: TreeParams) => setSp(toSearch(next))

  const goTo = (id: number) => {
    setDialogId(null)
    if (data.graph?.persons.some((p) => p.id === id)) { setSelected(id); canvas.current?.focusOn(id, 1); return }
    pendingFocus.current = id
    update({ mode: 'focus', clanId: null, side: 'both', personId: id, up: params?.up ?? 3, down: params?.down ?? 3 })
  }

  if (!params) {
    if (myPerson === null && clans.isSuccess && clans.data.length === 0) {
      return <Empty style={{ marginTop: '20vh' }} description="Chưa có dòng họ nào. Quản trị viên cần tạo dòng họ và chọn thủy tổ." />
    }
    if (clans.isError) return <Alert type="error" message={errorText((clans.error as { code?: string }).code)} style={{ margin: 16 }} />
    return <Spin style={{ display: 'block', margin: '20vh auto' }} />
  }

  const hovered = hover.card ? data.graph?.persons.find((p) => p.id === hover.card!.id) ?? null : null
  return (
    <div style={{ position: 'relative', height: 'calc(100vh - 64px)' }}>
      <TreeCanvas ref={canvas} graph={data.graph} layout={data.layout} keepCamera={data.keepCamera} selectedId={selected}
        onHover={hover.onHover} onViewChange={setView} onToggle={data.toggle}
        onClick={(id) => { hover.hide(); setSelected(id); setDialogId(id) }} />
      <div style={{ position: 'absolute', top: 8, left: 8, right: 8, pointerEvents: 'none' }}>
        <div style={{ pointerEvents: 'auto', display: 'inline-block', maxWidth: '100%' }}>
          <TreeToolbar params={params} clans={clans.data ?? []} myPersonId={myPerson} onChange={update} onPick={goTo}
            onFit={() => canvas.current?.fit()} />
        </div>
      </div>
      {data.error && <Alert type="error" showIcon style={{ position: 'absolute', top: 64, left: 8 }} message={errorText(data.error.code)} />}
      {data.loading && <Spin style={{ position: 'absolute', top: '50%', left: '50%' }} />}
      <div style={{ position: 'absolute', right: 8, bottom: 8 }}>
        <Minimap layout={data.layout} view={view} onNavigate={(x, y) => canvas.current?.moveCenterTo(x, y)} />
      </div>
      {hovered && hover.card && <HoverCard person={hovered} x={hover.card.x} y={hover.card.y} />}
      <PersonDialog personId={dialogId} onClose={() => setDialogId(null)} onNavigate={goTo} />
    </div>
  )
}
```
