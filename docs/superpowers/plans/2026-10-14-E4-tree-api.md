# E4 API xem cây Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Các API chỉ đọc cho giao diện cây: danh sách dòng họ, graph rút gọn có ETag (lọc nội/ngoại), focus quanh một người, tìm kiếm không dấu, hồ sơ, gia đình (kèm danh xưng), tiểu sử; ẩn ngày sinh đầy đủ của người còn sống với VIEWER.

**Architecture:** `GraphRepository` (JDBC, truy vấn theo mảng id, không N+1) → `GraphService` ghép `GraphResponse`; `SideFilter` là hàm thuần quyết định ai thuộc nhánh nội/ngoại; `ShallowEtagHeaderFilter` sinh ETag/304 cho hai endpoint graph. Thứ tự và danh xưng lấy từ `SiblingOrderService` (E2).

**Tech Stack:** Spring MVC, JdbcTemplate, PostgreSQL (`f_unaccent`), JUnit + MockMvc.

**Spec:** `docs/superpowers/specs/2026-10-14-gia-pha-design.md` (mục 4, 5); tài liệu gốc mục "Danh sách API", "Chế độ xem".

## Global Constraints

- Tiền tố `/api/v1`; mọi endpoint ở plan này cần tối thiểu `VIEWER` (đã đăng nhập).
- Graph rút gọn **không bao giờ** chứa ngày đầy đủ, chỉ `birthYear`/`deathYear`; `thumb` = `"/persons/{id}/photo?size=96&v={photoKey}"` hoặc `null` nếu chưa có ảnh (endpoint ảnh làm ở E6; FE tải ảnh bằng `fetch` kèm Bearer).
- Với VIEWER: người `alive=true` chỉ trả `birthYear`, **không** trả `birthDate`, `birthLunar`.
- Tìm kiếm không phân biệt dấu và hoa thường: `lower(f_unaccent(full_name)) LIKE`; `q` rỗng → 400 `VALIDATION_FAILED`; ký tự `%` `_` `\` trong `q` phải được escape; tối đa 50 kết quả.
- Lọc nội/ngoại: `paternal` = chỉ đi tiếp qua con của người **không phải nữ** (con gái có mặt như lá, con của con gái bị loại); `maternal` = chỉ những người sinh ra từ một người nữ trong dòng và hậu duệ của họ, cộng các tổ tiên nối tới họ; vợ/chồng của người được giữ cũng được giữ.
- Người đã xoá mềm không bao giờ xuất hiện.

## Review Focus

- Dòng họ chưa có thủy tổ hoặc chưa có thành viên: graph rỗng hợp lệ (`persons=[]`), không 500.
- `side` sai giá trị (`abc`) → 400, không 500.
- Tìm "nguyen van" ra "Nguyễn Văn A"; tìm "Đức" ra "Duc"; tìm `%` không trả toàn bộ bảng.
- VIEWER xem `/persons/{id}` của người còn sống: JSON **không có** trường ngày sinh đầy đủ (kể cả `birthLunar`).
- Con riêng/cùng cha khác mẹ nằm đúng nhóm trong tab Gia đình; một người không có cha mẹ → `parents=[]`, `siblings` rỗng.
- Graph của người đã xoá mềm giữa chừng: không có cạnh trỏ tới người không có trong `persons`.

import java.util.Locale;
import org.springframework.http.HttpStatus;
import vn.giapha.common.ApiException;

public enum Side {
    BOTH, PATERNAL, MATERNAL;

    public static Side parse(String s) {
        if (s == null || s.isBlank()) return BOTH;
        try {
            return valueOf(s.toUpperCase(Locale.ROOT));
        } catch (IllegalArgumentException e) {
            throw new ApiException(HttpStatus.BAD_REQUEST, "VALIDATION_FAILED", "side phải là both, paternal hoặc maternal");
        }
    }
}

`SideFilter.java`:
```java
package vn.giapha.tree;

import java.util.*;
import java.util.function.Function;
import vn.giapha.person.Gender;

public final class SideFilter {
    private SideFilter() {}

    public static Set<Long> apply(Side side, long rootId, Function<Long, List<Long>> childrenOf, Function<Long, Gender> genderOf) {
        Map<Long, Boolean> viaFemale = new LinkedHashMap<>();
        Map<Long, Long> parentOf = new HashMap<>();
        Map<Long, List<Long>> kids = new HashMap<>();
        Deque<Long> queue = new ArrayDeque<>();
        viaFemale.put(rootId, false);
        queue.add(rootId);
        while (!queue.isEmpty()) {
            long p = queue.poll();
            for (long c : childrenOf.apply(p)) {
                if (viaFemale.containsKey(c)) continue;
                viaFemale.put(c, viaFemale.get(p) || genderOf.apply(p) == Gender.F);
                parentOf.put(c, p);
                kids.computeIfAbsent(p, k -> new ArrayList<>()).add(c);
                queue.add(c);
            }
        }
        switch (side) {
            case BOTH:
                return new LinkedHashSet<>(viaFemale.keySet());
            case PATERNAL: {
                Set<Long> out = new LinkedHashSet<>();
                Deque<Long> stack = new ArrayDeque<>();
                stack.push(rootId);
                while (!stack.isEmpty()) {
                    long p = stack.pop();
                    out.add(p);
                    if (p == rootId || genderOf.apply(p) != Gender.F) {
                        for (long c : kids.getOrDefault(p, List.of())) stack.push(c);
                    }
                }
                return out;
            }
            default: {
                Set<Long> out = new LinkedHashSet<>();
                List<Long> order = new ArrayList<>(viaFemale.keySet());
                Collections.reverse(order); // con trước cha mẹ
                for (long p : order) {
                    if (viaFemale.get(p) || out.contains(p)) {
                        out.add(p);
                        Long parent = parentOf.get(p);
                        if (parent != null) out.add(parent);
                    }
                }
                return out;
            }
        }
    }
}

import java.util.List;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Repository;
import vn.giapha.person.Gender;
import vn.giapha.relation.ParentKind;

@Repository
public class GraphRepository {
    public record PersonRow(long id, String name, Gender gender, Integer birthYear, Integer deathYear,
                            boolean alive, String photoKey) {}

    private final JdbcTemplate jdbc;

    public GraphRepository(JdbcTemplate jdbc) { this.jdbc = jdbc; }

    private static Long[] arr(Collection<Long> ids) { return ids.toArray(Long[]::new); }

    public List<PersonRow> persons(Collection<Long> ids) {
        if (ids.isEmpty()) return List.of();
        return jdbc.query("""
            SELECT id, full_name, gender,
                   CASE WHEN birth_precision <> 'UNKNOWN' THEN EXTRACT(YEAR FROM birth_date)::int END AS by,
                   CASE WHEN death_precision <> 'UNKNOWN' THEN EXTRACT(YEAR FROM death_date)::int END AS dy,
                   is_alive, photo_key
            FROM person WHERE deleted_at IS NULL AND id = ANY(?) ORDER BY id
            """, (rs, i) -> new PersonRow(rs.getLong(1), rs.getString(2), Gender.valueOf(rs.getString(3)),
                (Integer) rs.getObject(4), (Integer) rs.getObject(5), rs.getBoolean(6), rs.getString(7)), (Object) arr(ids));
    }

    public List<GraphDtos.Union> unionsAmong(Collection<Long> ids) {
        if (ids.isEmpty()) return List.of();
        return jdbc.query("""
            SELECT id, partner_a_id, partner_b_id, union_order, status FROM union_rel
            WHERE partner_a_id = ANY(?) AND partner_b_id = ANY(?) ORDER BY id
            """, (rs, i) -> new GraphDtos.Union(rs.getLong(1), rs.getLong(2), rs.getLong(3), rs.getInt(4),
                UnionStatus.valueOf(rs.getString(5))), (Object) arr(ids), (Object) arr(ids));
    }

    public List<GraphDtos.Link> linksAmong(Collection<Long> ids) {
        if (ids.isEmpty()) return List.of();
        return jdbc.query("""
            SELECT parent_id, child_id, union_id, kind FROM parent_child
            WHERE parent_id = ANY(?) AND child_id = ANY(?) ORDER BY id
            """, (rs, i) -> new GraphDtos.Link(rs.getLong(1), rs.getLong(2), (Long) rs.getObject(3),

import java.util.*;
import java.util.stream.Collectors;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import vn.giapha.clan.*;

import vn.giapha.person.Gender;
import vn.giapha.relation.OrderInfo;
import vn.giapha.relation.SiblingOrderService;

@Service
@Transactional(readOnly = true)
public class GraphService {
    private final ClanRepository clans;
    private final ClanMemberRepository members;
    private final GraphRepository repo;
    private final SiblingOrderService orders;

    public GraphService(ClanRepository clans, ClanMemberRepository members, GraphRepository repo, SiblingOrderService orders) {
        this.clans = clans;
        this.members = members;
        this.repo = repo;
        this.orders = orders;
    }

    static String thumb(long id, String photoKey) {
        return photoKey == null ? null : "/persons/" + id + "/photo?size=96&v=" + photoKey;
    }

    public List<GraphDtos.ClanSummary> listClans() {
        return clans.findAll().stream()
            .map(c -> new GraphDtos.ClanSummary(c.getId(), c.getName(), c.getFounderPersonId(), members.findByClanId(c.getId()).size()))
            .toList();
    }

    public GraphDtos.Graph clanGraph(long clanId, Side side) {
        Clan clan = clans.findById(clanId)
            .orElseThrow(() -> new ApiException(HttpStatus.NOT_FOUND, "NOT_FOUND", "Không tìm thấy dòng họ"));
        List<ClanMember> all = members.findByClanId(clanId);
        if (clan.getFounderPersonId() == null || all.isEmpty()) {
            return new GraphDtos.Graph(clanId, clan.getFounderPersonId(), clan.getSiblingCountMode(), List.of(), List.of(), List.of());
        }
        Map<Long, ClanMember> byPerson = all.stream().collect(Collectors.toMap(ClanMember::getPersonId, m -> m));
        Set<Long> memberIds = byPerson.keySet();

        Set<Long> keep = new LinkedHashSet<>(memberIds);
        if (side != Side.BOTH) {
            Map<Long, List<Long>> kids = new HashMap<>();
            repo.linksAmong(memberIds).forEach(l -> kids.computeIfAbsent(l.parentId(), k -> new ArrayList<>()).add(l.childId()));
            Map<Long, Gender> gender = repo.persons(memberIds).stream()
                .collect(Collectors.toMap(GraphRepository.PersonRow::id, GraphRepository.PersonRow::gender));
            keep = new LinkedHashSet<>(SideFilter.apply(side, clan.getFounderPersonId(),
                id -> kids.getOrDefault(id, List.of()), id -> gender.getOrDefault(id, Gender.U)));
            // giữ vợ/chồng của người được giữ
            for (GraphDtos.Union u : repo.unionsAmong(memberIds)) {
                if (keep.contains(u.partnerAId()) && byPerson.get(u.partnerBId()).getMembership() == Membership.IN_LAW) keep.add(u.partnerBId());
                if (keep.contains(u.partnerBId()) && byPerson.get(u.partnerAId()).getMembership() == Membership.IN_LAW) keep.add(u.partnerAId());
            }
        }
        return assemble(clanId, clan.getFounderPersonId(), clan.getSiblingCountMode(), keep, byPerson, orders.computeForClan(clanId));
    }

    GraphDtos.Graph assemble(long clanId, Long rootId, SiblingCountMode mode, Set<Long> keep,
                             Map<Long, ClanMember> byPerson, Map<Long, OrderInfo> orderInfo) {
        List<GraphDtos.Person> persons = repo.persons(keep).stream().map(r -> {
            ClanMember m = byPerson.get(r.id());
            OrderInfo o = orderInfo.get(r.id());
            return new GraphDtos.Person(r.id(), r.name(), r.gender(), r.birthYear(), r.deathYear(), r.alive(),
                thumb(r.id(), r.photoKey()), o == null ? null : o.number(), o == null ? null : o.label(),
                m == null ? 1 : m.getGeneration(), m == null ? Membership.BLOOD : m.getMembership());
        }).toList();
        Set<Long> present = persons.stream().map(GraphDtos.Person::id).collect(Collectors.toSet());
        return new GraphDtos.Graph(clanId, rootId, mode, persons, repo.unionsAmong(present), repo.linksAmong(present));
    }
}

package vn.giapha.tree;

import java.util.*;
import java.util.stream.Collectors;
import org.springframework.http.HttpStatus;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import vn.giapha.clan.*;
import vn.giapha.common.ApiException;
import vn.giapha.person.Gender;
import vn.giapha.person.PersonRepository;
import vn.giapha.relation.OrderInfo;
import vn.giapha.relation.SiblingOrderService;

@Service
@Transactional(readOnly = true)
public class FocusService {
    private final JdbcTemplate jdbc;
    private final PersonRepository persons;
    private final GraphRepository repo;
    private final GraphService graphs;
    private final ClanRepository clans;
    private final ClanMemberRepository members;
    private final SiblingOrderService orders;

    public FocusService(JdbcTemplate jdbc, PersonRepository persons, GraphRepository repo, GraphService graphs,
                        ClanRepository clans, ClanMemberRepository members, SiblingOrderService orders) {
        this.jdbc = jdbc;
        this.persons = persons;
        this.repo = repo;
        this.graphs = graphs;
        this.clans = clans;
        this.members = members;
        this.orders = orders;
    }

    private List<long[]> parentsOf(long childId) { // {parentId, gender(M=0,F=1,U=2)}
        return jdbc.query("""
            SELECT pc.parent_id, p.gender FROM parent_child pc JOIN person p ON p.id = pc.parent_id AND p.deleted_at IS NULL
            WHERE pc.child_id = ? ORDER BY pc.id""",
            (rs, i) -> new long[]{rs.getLong(1), "M".equals(rs.getString(2)) ? 0 : "F".equals(rs.getString(2)) ? 1 : 2}, childId);
    }

    private List<Long> childrenOf(long parentId) {
        return jdbc.queryForList("""
            SELECT pc.child_id FROM parent_child pc JOIN person p ON p.id = pc.child_id AND p.deleted_at IS NULL
            WHERE pc.parent_id = ? ORDER BY pc.id""", Long.class, parentId);
    }

    private List<Long> partnersOf(long personId) {
        return jdbc.queryForList("""
            SELECT CASE WHEN partner_a_id = ? THEN partner_b_id ELSE partner_a_id END
            FROM union_rel WHERE partner_a_id = ? OR partner_b_id = ?""", Long.class, personId, personId, personId);
    }

    public GraphDtos.Graph focus(long personId, int up, int down) {
        persons.findByIdAndDeletedAtIsNull(personId)
            .orElseThrow(() -> new ApiException(HttpStatus.NOT_FOUND, "NOT_FOUND", "Không tìm thấy người này"));
        int u = Math.max(0, Math.min(10, up)), d = Math.max(0, Math.min(10, down));

        Set<Long> keep = new LinkedHashSet<>();
        keep.add(personId);

        long top = personId;
        Set<Long> parentsOfSelf = new LinkedHashSet<>();
        for (long[] p : parentsOf(personId)) parentsOfSelf.add(p[0]);
        for (int i = 0; i < u; i++) {
            List<long[]> ps = parentsOf(top);
            if (ps.isEmpty()) break;
            long[] chosen = ps.stream().filter(x -> x[1] == 0).findFirst().orElse(ps.get(0));
            top = chosen[0];
            keep.add(top);
        }
        // hậu duệ
        Deque<long[]> q = new ArrayDeque<>();
        q.add(new long[]{personId, 0});
        while (!q.isEmpty()) {
            long[] cur = q.poll();
            if (cur[1] >= d) continue;
            for (long c : childrenOf(cur[0])) if (keep.add(c)) q.add(new long[]{c, cur[1] + 1});
        }
        // anh chị em
        for (long parent : parentsOfSelf) for (long c : childrenOf(parent)) keep.add(c);
        // vợ/chồng của mọi người đang có (một lượt, không lan tiếp)
        for (long p : new ArrayList<>(keep)) keep.addAll(partnersOf(p));

        List<ClanMember> mine = jdbc.queryForList("SELECT DISTINCT clan_id FROM clan_member WHERE person_id = ? ORDER BY clan_id", Long.class, personId)
            .stream().findFirst().map(cid -> members.findByClanId(cid)).orElse(List.of());
        long clanId = mine.isEmpty() ? 0 : mine.get(0).getClanId();
        Map<Long, ClanMember> byPerson = mine.stream().collect(Collectors.toMap(ClanMember::getPersonId, m -> m));
        Map<Long, OrderInfo> orderInfo = clanId == 0 ? Map.of() : orders.computeForClan(clanId);
        SiblingCountMode mode = clanId == 0 ? SiblingCountMode.PER_UNION
            : clans.findById(clanId).map(Clan::getSiblingCountMode).orElse(SiblingCountMode.PER_UNION);
        return graphs.assemble(clanId, top, mode, keep, byPerson, orderInfo);
    }
}

        persons.findByIdAndDeletedAtIsNull(personId)
            .orElseThrow(() -> new ApiException(HttpStatus.NOT_FOUND, "NOT_FOUND", "Không tìm thấy người này"));

        List<Long> clan = jdbc.queryForList("SELECT clan_id FROM clan_member WHERE person_id = ? ORDER BY clan_id LIMIT 1", Long.class, personId);
        Map<Long, OrderInfo> orderInfo = clan.isEmpty() ? Map.of() : orders.computeForClan(clan.get(0));

        // cha mẹ
        List<Long> parentIds = jdbc.queryForList("SELECT parent_id FROM parent_child WHERE child_id = ? ORDER BY id", Long.class, personId);
        // con, kèm hôn phối
        record ChildLink(long childId, Long unionId) {}
        List<ChildLink> childLinks = jdbc.query("SELECT child_id, union_id FROM parent_child WHERE parent_id = ? ORDER BY id",
            (rs, i) -> new ChildLink(rs.getLong(1), (Long) rs.getObject(2)), personId);
        // hôn phối
        record UnionRow(long id, long partnerId, int order, UnionStatus status, LocalDate start, LocalDate end) {}
        List<UnionRow> unionRows = jdbc.query("""
            SELECT id, CASE WHEN partner_a_id = ? THEN partner_b_id ELSE partner_a_id END, union_order, status, start_date, end_date
            FROM union_rel WHERE partner_a_id = ? OR partner_b_id = ? ORDER BY union_order, id""",
            (rs, i) -> new UnionRow(rs.getLong(1), rs.getLong(2), rs.getInt(3), UnionStatus.valueOf(rs.getString(4)),
                rs.getDate(5) == null ? null : rs.getDate(5).toLocalDate(), rs.getDate(6) == null ? null : rs.getDate(6).toLocalDate()),
            personId, personId, personId);
        // anh chị em: mọi con của cha mẹ mình
        record SibLink(long childId, long parentId) {}
        List<SibLink> sibLinks = parentIds.isEmpty() ? List.of() : jdbc.query(
            "SELECT child_id, parent_id FROM parent_child WHERE parent_id = ANY(?) AND child_id <> ?",
            (rs, i) -> new SibLink(rs.getLong(1), rs.getLong(2)), (Object) parentIds.toArray(Long[]::new), personId);
        Set<Long> sibIds = sibLinks.stream().map(SibLink::childId).collect(Collectors.toCollection(LinkedHashSet::new));
        Map<Long, List<Long>> parentsOfSib = new HashMap<>();
        if (!sibIds.isEmpty()) {
            jdbc.query("SELECT child_id, parent_id FROM parent_child WHERE child_id = ANY(?)",
                rs -> { parentsOfSib.computeIfAbsent(rs.getLong(1), k -> new ArrayList<>()).add(rs.getLong(2)); },
                (Object) sibIds.toArray(Long[]::new));
        }

        Set<Long> need = new LinkedHashSet<>(parentIds);
        unionRows.forEach(u -> need.add(u.partnerId()));
        childLinks.forEach(c -> need.add(c.childId()));
        need.addAll(sibIds);
        parentsOfSib.values().forEach(need::addAll);
        Map<Long, Row> rows = load(need);

        java.util.function.Function<Long, PersonRef> ref = id -> {
            Row r = rows.get(id);
            if (r == null) return null;
            OrderInfo o = orderInfo.get(id);
            return new PersonRef(r.id(), r.name(), r.gender(), r.by(), r.dy(), r.alive(), o == null ? null : o.label());
        };
        java.util.function.Function<Collection<Long>, List<PersonRef>> refs =
            ids -> ids.stream().map(ref).filter(Objects::nonNull).toList();

        Set<Parent> mine = parentIds.stream().filter(rows::containsKey).map(id -> new Parent(id, rows.get(id).gender())).collect(Collectors.toSet());
        List<Long> full = new ArrayList<>(), halfF = new ArrayList<>(), halfM = new ArrayList<>();
        for (long sid : sibIds) {
            if (!rows.containsKey(sid)) continue;
            Set<Parent> theirs = parentsOfSib.getOrDefault(sid, List.of()).stream().filter(rows::containsKey)
                .map(id -> new Parent(id, rows.get(id).gender())).collect(Collectors.toSet());
            Kind k = SiblingClassifier.classify(mine, theirs);
            (k == Kind.FULL ? full : k == Kind.HALF_SAME_FATHER ? halfF : halfM).add(sid);
        }

        Set<Long> unionIds = unionRows.stream().map(UnionRow::id).collect(Collectors.toSet());
        List<SpouseFamily> spouses = new ArrayList<>();
        for (UnionRow u : unionRows) {
            PersonRef partner = ref.apply(u.partnerId());
            if (partner == null) continue;
            List<Long> kids = childLinks.stream().filter(c -> Objects.equals(c.unionId(), u.id())).map(ChildLink::childId).toList();
            spouses.add(new SpouseFamily(u.id(), u.order(), u.status(), u.start(), u.end(), partner, refs.apply(kids)));
        }
        List<Long> other = childLinks.stream().filter(c -> c.unionId() == null || !unionIds.contains(c.unionId()))
            .map(ChildLink::childId).toList();
        return new FamilyResponse(personId, refs.apply(parentIds), spouses, refs.apply(other), refs.apply(full), refs.apply(halfF), refs.apply(halfM));
    }
}
```
