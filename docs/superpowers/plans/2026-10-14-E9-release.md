# E9 Kiểm thử và triển khai Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đưa hệ thống lên máy chủ thật, đạt điều kiện nghiệm thu M4: ma trận phân quyền được kiểm bằng test cho **mọi** endpoint, nhập đủ 2.000 người từ Excel, mở cây < 2 giây và popup < 300 ms, HTTPS, sao lưu DB hằng ngày và **đã thử khôi phục**.

**Architecture:** Bảo vệ hai lớp ở BE (quy tắc URL trong `SecurityConfig` + `@PreAuthorize`) với một bài test "ma trận" liệt kê toàn bộ endpoint và một bài test "bảo vệ" thất bại nếu có endpoint mới chưa được liệt kê/chưa có trong OpenAPI. Triển khai bằng Docker Compose: Caddy (HTTPS tự động + phục vụ FE + proxy `/api`) → Spring Boot → PostgreSQL/MinIO; một container sao lưu chạy cron.

**Tech Stack:** JUnit/MockMvc/Testcontainers, Gradle (`perfTest`), JUnit `@Tag("perf")`, Playwright (đo FE), Docker Compose, Caddy 2, `pg_dump`/`pg_restore`, shell.

**Spec:** `docs/superpowers/specs/2026-10-14-gia-pha-design.md`; tài liệu gốc mục "Mốc và điều kiện nghiệm thu" (M4), "Quy ước hoàn thành mỗi việc".

## Global Constraints

- Ma trận quyền (nguồn chuẩn): xem E6 Global Constraints + E7/E8; EDITOR+ = `hasAnyRole('EDITOR','ADMIN')` (không dựa vào `RoleHierarchy` ở lớp URL).
- Mục tiêu hiệu năng (đo trên máy chủ thật): mở cây lần đầu **< 2 giây**, mở popup **< 300 ms**; BE `GET /clans/{id}/graph` cho 2.000 người **< 800 ms** (không tính mạng) và JSON nén gzip **< 120 KB**; 10.000 người **< 3 giây**.
- Cổng 80/443 là cổng duy nhất mở ra Internet; PostgreSQL, MinIO, backend **không** publish cổng ra host ở môi trường thật.
- Cookie refresh phải `Secure` (`COOKIE_SECURE=true`); Swagger UI tắt ở môi trường thật (`SWAGGER_ENABLED=false`).
- Sao lưu DB hằng ngày lúc 02:30 UTC, giữ 14 ngày; ảnh (volume MinIO) sao lưu cùng lịch.
- Mọi bí mật (mật khẩu DB, JWT secret, khoá MinIO, mật khẩu admin đầu tiên) chỉ nằm trong `.env.prod` trên máy chủ, **không** commit.

## Review Focus

- Thêm một endpoint mới mà quên khai báo quyền → test "bảo vệ" phải **fail** (không âm thầm cho phép).
- `403` phải xảy ra **trước** khi kiểm tra nội dung body (VIEWER gửi body sai vẫn nhận 403, không phải 400).
- Khôi phục sao lưu ra DB tạm cho đúng số người, đúng số quan hệ như DB gốc — không chỉ "lệnh chạy xong".
- Triển khai lần hai (`up -d --build`) với volume cũ không chạy lại/không hỏng migration Flyway.
- Mở trang bằng `http://` tự chuyển `https://`; cookie `refresh_token` có cờ `Secure; HttpOnly; SameSite=Strict`.
- Đo hiệu năng ở lần mở **đầu tiên** (IndexedDB trống) chứ không chỉ lần hai (đã cache).

set -euo pipefail
BACKUP_DIR="${BACKUP_DIR:-/backups}"

#!/usr/bin/env bash
set -euo pipefail
BACKUP_DIR="${BACKUP_DIR:-/backups}"
LATEST="$(ls -1t "$BACKUP_DIR"/giapha-*.dump | head -n 1)"
TMP="giapha_verify_$$"
/usr/local/bin/restore.sh "$LATEST" "$TMP"

q() { psql -h "$PGHOST" -U "$PGUSER" -d "$1" -Atc "$2"; }
status=0
for t in person union_rel parent_child clan clan_member app_user audit_log; do
  live="$(q "$PGDATABASE" "SELECT count(*) FROM $t")"
  restored="$(q "$TMP" "SELECT count(*) FROM $t")"
  if [ "$restored" -gt "$live" ]; then echo "BẤT THƯỜNG $t: khôi phục=$restored > hiện tại=$live"; status=1; fi
  echo "$t: hiện tại=$live, bản sao lưu=$restored"
done
dropdb -h "$PGHOST" -U "$PGUSER" "$TMP"
